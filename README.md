# Почта 24

Одностраничный сайт современной почтовой службы. Интерфейс построен вокруг основных пользовательских задач: отправка и отслеживание посылок, просмотр тарифов, поиск отделений и быстрый доступ к популярным услугам.

## Что реализовано

- отслеживание отправления по трек-номеру;
- быстрые действия для основных почтовых услуг;
- блоки с тарифами и вариантами доставки;
- поиск ближайших отделений;
- адаптивная версия для компьютеров и мобильных устройств;
- интерактивные элементы без сторонних библиотек.
