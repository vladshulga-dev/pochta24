# Почта 24

Одностраничный сайт почтовой службы с отслеживанием отправлений, быстрыми действиями, тарифами, поиском отделений и адаптивной версткой.

## Стек

- HTML
- CSS
- JavaScript

## Локальный запуск

Откройте `index.html` в браузере или запустите любой локальный статический сервер в папке проекта.

## GitHub Pages

После публикации репозитория `pochta24` сайт будет доступен по адресу:

`https://vladshulga-dev.github.io/pochta24/`

Для GitHub Pages выберите публикацию из ветки `main`, папка `/ (root)`.
